** WHERE IT STANDS
Custom symbols' steps 0 to 3 are built and committed on =custom-symbols=,
unreleased:

- *Step 0*: nazca's own =gl::Context=.
- *Step 1*: symbols, the atlas and the 256 x 7 palette.
- *Step 2*: markers, on screen, in picks and in SVG from pixels. Their SVG
  markup moved to step 5 (§ OPEN QUESTIONS 8).
- *Step 3*: dashes, and a border two polygons share drawn once, by the
  last feature fed that outlines it (§ OPEN QUESTIONS 9). Checked natively
  and in Chrome's WebGL2 by the spike's dash check (=--check-dashes=, X in
  the browser).
- *Step 3's two additions*, built 2026-11-23 and checked natively:
  - /A far line start keeps its phase/: =Mesh::distances= are =f64=, and
    the upload gives each run of chained segments a shared =f32= base and
    each segment its offset (=SEGMENT_BYTES= 40). No jitter between
    vertices at 1,000 or 5,000 km along; the run is off by one error, up
    to about a pixel at zoom 20.4, a jump where it meets the next run.
  - /=MeshBuilder::line_length=/ measures a piece as nazca does, so the
    next piece's start joins exactly: 0.0 pixels at every level in the
    dash check, measured by a different tile at the level than the seam's.

§ CHECKS (/Dashes/, /A far line start/) has the runs and numbers.

** RUNNING THINGS
- Native: =cargo run --release --features gl --example spike=. Add
  =-- --outlines dashed= to start dashed. D cycles the outlines, H hovers
  the county picked last, and =--check-dashes= runs the check and exits.
- Browser: =cd spike-web && wasm-pack build --target web --release=, then
  =python3 -m http.server= there and open the page. X runs the dash check
  and logs its report to the console.
- Tests: =cargo test --all-features=.
